# Порівняльне тестування search_notes (До і Після RAG)

## Тестові запитання
1. Які основні правила безпеки визначено у guardrails?
2. Як працює протокол handoff між ролями оркестрації?
3. Що є джерелом істини для Obsidian-нотаток?

## Результати порівняння
- **До RAG (Точний збіг):** Пошук працював лише за ключовими словами у назвах чи тексті нотаток. Якщо формулювання запитання відрізнялося від тексту в нотатці, інструмент не знаходив релевантних даних.
- **Після RAG (Семантичний пошук):** Завдяки embeddings та vector search (ag/vector_search.py), агент знаходить релевантні фрагменти навіть за змістовним описом або синонімами, що суттєво підвищує точність відповідей у skills та оркестрації.

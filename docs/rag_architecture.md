# Context Engineering: RAG Architecture

## 1. Призначення
Заміна точного збігу у search_notes на семантичний пошук на основі локальних embeddings без зміни інтерфейсу MCP-сервера.

## 2. Стратегія Chunking
Природним чанком є окрема Obsidian-нотатка (.md файл) або її розділи за заголовками.

## 3. Зберігання індексу
Локальний векторний індекс зберігається у палці rag_index/ (доданій до .gitignore як похідний артефакт).

# Вимоги до застосунку (App Requirements)

## 1. Функціональні вимоги
- Імпорт вхідних JSON/CSV файлів з телеметрією.
- Валідація структур даних через Pydantic-моделі.
- Агрегація метрик за часовими інтервалами (хвилина/година).
- Генерація алертів при критичних показниках.
- Експорт результатів у Parquet/CSV.
- CLI-інтерфейс на базі Typer.

## 2. Нефункціональні вимоги
- Швидкість обробки: файл на 10 000 рядків має оброблятися менш ніж за 3 секунди.
- Надійність: чітке логування помилок валідації без падіння всього процесу.
- Чистота коду: дотримання стандарту PEP 8 та наявність типів (Type Hints).

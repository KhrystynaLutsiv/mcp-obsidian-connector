# ЗАВДАННЯ

## Застосунок
* **Назва:** Industrial IoT Telemetry Pipeline & CLI
* **Короткий опис:** Сервіс для валідації, агрегації та моніторингу телеметричних даних промислового обладнання.
* **Цільові користувачі:** Інженери з даних та технічні оператори.
* **Технологічний стек:** Python 3.10+, Pydantic, Pandas, DuckDB, Typer, Pytest.

## Обрана агентна IDE
* **Інструмент:** Cursor
* **Обґрунтування:** Підтримка MCP-серверів для конекторів до бази знань, виконання команд bash, налаштування проєктних правил.

## Мета harness
Прискорити розробку стандартизованих компонентів обробки даних, забезпечити високу тестову покриваність та дотримання архітектурних конвенцій проєкту автономним агентом.

## Цільові задачі агента
1. Генерація каркасу нових модулів та схем валідації даних.
2. Автоматична генерація unit-тестів для пайплайнів обробки.
3. Рев'ю коду на дотримання стилю команди.
4. Синхронізація документації з кодовою базою.
